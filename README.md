# Object-Oriented Shopping & Banking Simulator (oop-shopping-sim)

A C++ console application project that simulates banking operations, e-commerce shopping, and user account management using Object-Oriented Programming (OOP) principles.

This was a rewrite project that I was working on 2025 to further understand core C++ concepts.
